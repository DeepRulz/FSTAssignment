# FST Assignment

This repository contains the assignments for the **Finite State Transducers (FST)** course.

## Assignment 1 (ass1)

- **Objective**: Implement a basic finite state transducer that converts input strings based on a given set of transformation rules.
- **Tasks**:
  - Define the state diagram and transition functions.
  - Implement the transducer in your preferred programming language.
  - Provide a set of test cases demonstrating the correct behavior of the transducer.
- **Deliverables**: Source code, a README with usage instructions, and the test suite.

## Assignment 2 (ass2)

- **Objective**: Extend the transducer from Assignment 1 to handle more complex transformations, including context‑dependent rules and epsilon transitions.
- **Tasks**:
  - Add support for context‑sensitive replacements.
  - Implement epsilon (null) transitions where appropriate.
  - Optimize the transducer for performance on larger input strings.
  - Include a comprehensive set of unit tests covering edge cases.
- **Deliverables**: Updated source code, performance analysis documentation, and an expanded test suite.
